# FutSim 2026 - Ultimate Edition (Render Ready)

Este é um jogo multiplayer simulador de partidas de futebol com **interface extremamente polida**, ranking global, duelos ao vivo e sistema de chats.

## Como rodar localmente
1. Instale o Node.js
2. Abra o terminal: `npm install`
3. Inicie o servidor: `npm start`
4. Acesse: `http://localhost:3000`

## Como hospedar de graça no Render
1. Faça upload destes arquivos para o GitHub.
2. Acesse [Render](https://render.com/) > New Web Service.
3. Conecte o repositório.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. Deploy!
